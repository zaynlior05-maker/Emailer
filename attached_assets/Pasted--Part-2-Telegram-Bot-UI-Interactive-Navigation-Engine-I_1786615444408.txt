# Part 2: Telegram Bot UI & Interactive Navigation Engine
In this second stage, we build the interactive menu system inside Telegram. This is the control panel where users select email templates, inject variable data ({{ recipient_name }}, {{ seed_phrase }}, etc.), preview the rendered HTML, and trigger sending.
## 1. User Interface Navigation Flow
The bot operates through a clean **Inline Keyboard Menu** hierarchy to avoid cluttering the chat with repeated messages.

## 2. State Management (bot/states.py)
Using a finite state machine (ConversationHandler), we keep track of where the user is in the workflow:
```python
from enum import IntEnum, auto

class MailerState(IntEnum):
    MAIN_MENU = auto()
    SELECT_CATEGORY = auto()
    SELECT_TEMPLATE = auto()
    INPUT_RECIPIENT_EMAIL = auto()
    INPUT_RECIPIENT_NAME = auto()
    INPUT_DYNAMIC_VARS = auto()
    CONFIRM_DISPATCH = auto()

```
## 3. Dynamic Inline Keyboard Builders (bot/keyboards/menus.py)
Every menu should be rendered dynamically using helper functions so menus update automatically when new template categories or brands are added.
### Main Menu Markup
```python
from telegram import InlineKeyboardButton, InlineKeyboardMarkup

def get_main_menu_keyboard() -> InlineKeyboardMarkup:
    keyboard = [
        [InlineKeyboardButton("📧 Create New Mail", callback_data="nav_create_mail")],
        [
            InlineKeyboardButton("🎨 Templates", callback_data="nav_templates"),
            InlineKeyboardButton("⚙️ Settings", callback_data="nav_settings"),
        ],
        [InlineKeyboardButton("📊 Dispatch Logs", callback_data="nav_logs")],
    ]
    return InlineKeyboardMarkup(keyboard)

def get_category_keyboard(categories: list[str]) -> InlineKeyboardMarkup:
    keyboard = []
    # Display categories in a 2-column grid
    row = []
    for cat in categories:
        row.append(InlineKeyboardButton(f"📁 {cat}", callback_data=f"cat_{cat}"))
        if len(row) == 2:
            keyboard.append(row)
            row = []
    if row:
        keyboard.append(row)
    
    keyboard.append([InlineKeyboardButton("⬅️ Back to Main Menu", callback_data="nav_main")])
    return InlineKeyboardMarkup(keyboard)

```
## 4. Handler Logic & Callbacks (bot/handlers/menu_handler.py)
Whenever a user taps an inline button, Telegram fires a CallbackQuery. Always acknowledge the query immediately with await query.answer() to stop the loading icon spinner on the button.
```python
from telegram import Update
from telegram.ext import ContextTypes
from bot.keyboards.menus import get_main_menu_keyboard, get_category_keyboard

async def start_command(update: Update, context: ContextTypes.DEFAULT_TYPE):
    """Entry point for /start command."""
    welcome_text = (
        "<b>Welcome to Mailer Control Panel</b>\n\n"
        "Select an option below to start building and dispatching emails."
    )
    await update.message.reply_text(
        text=welcome_text,
        parse_mode="HTML",
        reply_markup=get_main_menu_keyboard()
    )

async def handle_navigation(update: Update, context: ContextTypes.DEFAULT_TYPE):
    """Handles inline menu navigation without sending new messages."""
    query = update.callback_query
    await query.answer()  # Clears button loading state
    
    data = query.data
    
    if data == "nav_create_mail":
        categories = ["Crypto", "UK Bank", "US Bank", "AUS Bank", "Finance"]
        await query.edit_message_text(
            text="<b>Step 1: Select Target Category</b>",
            parse_mode="HTML",
            reply_markup=get_category_keyboard(categories)
        )
    elif data == "nav_main":
        await query.edit_message_text(
            text="<b>Main Menu</b>\nSelect an option below:",
            parse_mode="HTML",
            reply_markup=get_main_menu_keyboard()
        )

```
