## 2. Dynamic Template Renderer (engine/renderer.py)
We use **Jinja2** to inject dynamic variables into the base HTML layout files stored in templates/html/.
```python
import json
from pathlib import Path
from jinja2 import Environment, FileSystemLoader

class TemplateRenderer:
    def __init__(self, templates_dir: str = "templates/html", brands_path: str = "config/brands.json"):
        self.env = Environment(loader=FileSystemLoader(templates_dir))
        with open(brands_path, "r") as f:
            self.brands = json.load(f)

    def render(self, brand_key: str, template_name: str, context_vars: dict) -> str:
        """
        Loads template HTML, merges brand config + context variables, 
        and produces rendered HTML string.
        """
        # Fetch brand design configuration
        brand_config = self.brands.get(brand_key, self.brands.get("default"))
        
        # Merge brand theme settings with user input variables
        full_context = {
            "brand": brand_config,
            **context_vars
        }

        # Load and render the target template file
        template = self.env.get_template(f"{template_name}.html")
        rendered_html = template.render(full_context)
        return rendered_html

```
## 3. Automatic CSS Inlining (engine/inliner.py)
Email clients like Gmail, Outlook, and Yahoo strip <style> blocks in headers. **All CSS must be converted into inline style="" attributes** before dispatching.
We use premailer to convert rendered HTML automatically:
```python
from premailer import transform

def inline_email_css(raw_html: str) -> str:
    """
    Converts embedded <style> tags and CSS classes into inline CSS style attributes.
    """
    inlined_html = transform(
        raw_html,
        keep_style_tags=False,
        strip_important=False
    )
    return inlined_html

```
## 4. Live Telegram Email Preview Handler
Before sending an email to a recipient, the admin must be able to review the exact rendered output inside Telegram.
```python
from telegram import Update
from telegram.ext import ContextTypes
from engine.renderer import TemplateRenderer
from engine.inliner import inline_email_css

renderer = TemplateRenderer()

async def generate_preview_callback(update: Update, context: ContextTypes.DEFAULT_TYPE):
    query = update.callback_query
    await query.answer()

    # Retrieve user choices stored in user_data session state
    user_data = context.user_data
    brand = user_data.get("selected_brand", "coinbase")
    template = user_data.get("selected_template", "case_review")
    vars_dict = user_data.get("template_vars", {})

    # 1. Render raw Jinja HTML
    raw_html = renderer.render(brand_key=brand, template_name=template, context_vars=vars_dict)
    
    # 2. Convert CSS to inline
    final_html = inline_email_css(raw_html)
    
    # Save processed HTML to context for the send stage
    context.user_data["final_html"] = final_html

    # 3. Send HTML code snippet/file preview to Telegram Admin
    await query.message.reply_document(
        document=bytes(final_html, "utf-8"),
        filename=f"preview_{brand}_{template}.html",
        caption="<b>HTML Email Preview Generated</b>\nInspect file above before dispatching."
    )

```
