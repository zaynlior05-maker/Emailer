
### 1. High-Level System Architecture
The Telegram Bot acts as an interactive control panel (Admin Control Panel).
```text
[ Telegram User / Admin ]
           │
           ▼
[ Telegram Bot UI (python-telegram-bot / aiogram) ]
           │
           ├────────► [ User State & Session Manager ]
           │
           ├────────► [ Dynamic Template Factory ]
           │                 │
           │                 ▼
           │        [ Generates Inlined HTML Email ]
           │
           ▼
[ Database (PostgreSQL / SQLite) ] ──► Stores Users, Logs & Configurations
           │
           ▼
[ Mail Engine ] ──► Dispatches Email to Target Recipient

```
### 2. Recommended Project Folder Structure
Your developer should set up the repository on GitHub using this clean directory structure:
```text
endless-telegram-mailer/
├── assets/
│   ├── logos/              # Brand SVG/PNG logos (Binance, Coinbase, Ledger, etc.)
│   └── icons/              # Dynamic UI badges & icons
├── config/
│   ├── settings.py         # Global project configuration & env loading
│   └── brands.json         # Master brand theme configurations (colors, logos)
├── templates/
│   ├── html/               # Raw HTML email template bases
│   └── json/               # Template metadata mapping files
├── bot/
│   ├── handlers/           # Telegram command and button callbacks
│   ├── keyboads/           # Inline keyboard button layouts
│   └── states.py           # User conversation workflow states
├── engine/
│   ├── renderer.py         # Template rendering & Jinja2 engine
│   ├── inliner.py          # Automatic CSS inline converter
│   └── mailer.py           # SMTP/API dispatch service
├── database/
│   ├── models.py           # Database schema (Users, Logs, Templates)
│   └── connection.py       # Database connection helper
├── .env.example            # Template for environment variables
├── Dockerfile              # Container deployment for Railway
├── Procfile                # Deployment entry point for Railway
├── requirements.txt        # Python dependency list
└── main.py                 # Main application entry point

```
### 3. Required Environment Variables (.env)
Every sensitive configuration item must be loaded via Environment Variables so Railway can safely manage them:
```env
# Telegram Configuration
TELEGRAM_BOT_TOKEN=your_bot_token_from_botfather
TELEGRAM_ADMIN_IDS=123456789,987654321

# Database Configuration
DATABASE_URL=postgresql://user:password@localhost:5432/mailer_db

# Email Server / SMTP Settings
SMTP_HOST=smtp.yourserver.com
SMTP_PORT=587
SMTP_USER=your_smtp_username
SMTP_PASS=your_smtp_password
DEFAULT_SENDER_NAME="Security Support"
DEFAULT_SENDER_EMAIL=support@yourdomain.com

# System Environment
ENVIRONMENT=production

```
